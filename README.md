# Student Performance Analysis (Power BI Project)

## 📌 Project Overview
This project analyzes student performance data (marks, attendance, study hours, etc.) using Power BI.  
The goal is to identify trends, factors affecting performance, and generate insights to improve academic results.

## 🎯 Objectives
- Load and preprocess student dataset
- Analyze subject-wise and overall performance
- Identify factors like study hours and attendance
- Compare performance across different groups/classes
- Visualize data using bar, pie, and line charts
- Generate actionable insights

## 📊 Tools Used
- Power BI Desktop
- Excel/CSV dataset

## 🚀 How to Use
1. Download the `.pbix` file from the folder.
2. Open it in Power BI Desktop.
3. Explore the dashboard and visuals.
4. Modify or update with your own dataset if needed.

## 📝 Insights
- Attendance strongly correlates with performance.
- Subject-wise trends highlight areas needing improvement.
- Group comparisons reveal differences across classes.
